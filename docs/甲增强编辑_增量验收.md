本批自动验证与本人操作分别记录。旧M0输入法/DPI、H-010恢复、M1已确认结果继续保留；原属性/样式/标签已做过的项目不重复全套。本清单只检查新增入口与两条筛选修正。待乙丙非作者复核，不据此宣布M2/M3通过。

## 启动和样例

使用本批固定候选中的“启动本次候选.cmd”，经文件→打开“样例/01-basic.lingya”，先另存为自己的测试文件。候选具体路径写在本聊天最终交付中。日常main入口继续对应已合主线，待审分支使用固定候选。

以下“应用”均会写入工程并可撤销；管理窗口里的“关闭”保留已经应用的记录，尚未应用的草稿不保存。测试中使用自己的副本，不覆盖原资料。

## 1 工作表与鱼骨入口

1. 工作表→新建工作表，类型选鱼骨图，输入测试名称，先取消：数量不变。再创建：下拉切到新表，鱼头、主骨、六类斜骨可见。
2. 工作表→工作表改名，输入中文名称。通过下拉在原导图与鱼骨间切换，内容分别保留。
3. 在鱼骨表执行“导图／鱼骨切换”，预期同一内容变为导图；一次撤销恢复鱼骨，标题、备注等不丢。
4. 删除当前新表，先取消，表保留；再确认删除，回到剩余表，一次撤销恢复。最后一张表不能删除。
5. 需要补看删表保护时，另开受控样例02-delete-impact.lingya，新建第二表后切回原表再删除。预期提示仍有文稿、卡片或路线，表及这些内容均保留；不需要自己造卡片或改JSON。

## 2 剪贴板

1. 选原导图“阶段1”，Ctrl+C；选中心主题Ctrl+V：新增一个完整副本，含子主题，一次撤销撤整份副本。
2. 再选“阶段1”，Ctrl+X：源主题仍在、边框为虚线；选“阶段2”，Ctrl+V：阶段1及后代移到阶段2下。一次撤销回原处。
3. 选根Ctrl+X：提示不能剪切根，原数据保留。把主题剪切后尝试粘到它自己的后代：拒绝且源保留。按Esc取消待剪切标记。
4. 剪切后先改一个主题名称，再粘贴：提示源修订变化需重新剪切。跨工作表剪切明确拒绝并保留源；跨表普通复制可用。
5. 在属性/备注文本框里正常使用Ctrl+C/V，预期操作文字，不误触主题粘贴。

## 3 全局默认与局部覆盖

1. 编辑→工作表默认样式：改默认填充色、字号、连线颜色/宽度/虚线，应用后未覆盖节点和树边一起变化，一次撤销整组恢复。
2. 给一个节点设置不同的局部填充色，再修改默认填充色：局部节点保留自己的颜色，其余随默认变化。
3. 默认样式窗口取消不写入，未修改直接应用不增加一次撤销。较小窗口中字段可滚动，应用/取消可见。

## 4 关系线

1. 编辑→关系线，选择两个不同主题，输入标签，选择终点箭头，应用。关闭后可见独立关系曲线、标签和箭头。
2. 再打开，点击已建的列表记录，修改颜色、宽度、虚线和双向箭头，应用；原端点保持，一次撤销回原样式。
3. 点击记录→删除所选，关闭后线消失；撤销恢复。
4. 同一主题作起终点时应用应显示原因，窗口保持打开，不能生成非法关系。

## 5 外框、概要与结构随动

1. 编辑→外框与概要，父主题选中心主题；列表点击第一和第三项，应用应拒绝，说明需要至少两个同父连续兄弟。
2. 改选连续两项或三项，文本输入中文，颜色可留空，类型外框，应用。关闭后框包含这些分支及可见后代。双侧导图分左右绘制同一组，不把中心主题框入。
3. 再新建同范围的概要，输入一段较长文字。文字应在独立侧边区域，可滚动查看，不盖住节点正文。
4. 在大纲把另一同级分支拖到两个成员之间：移入者并入框；把框成员拖到另一父主题下：它从原框摘除；剩余不足两个时框移除。界面立即重绘，状态栏有调整提示，一次撤销恢复。
5. 列表选已有框，改文本/颜色/成员后应用；删除所选后消失，撤销恢复。清空颜色再应用，后续保存重开仍应正常。

## 6 批注

1. 选主题→编辑→主题批注，输入作者和两行中文正文，先关闭：不产生记录。
2. 重新输入并应用，记录显示作者、时间、正文；节点备注不被改写。
3. 点记录→标记已解决／重新打开，状态改变；关闭后一次撤销能还原这次状态。
4. 正文空白时应用拒绝，错误提示中文，窗口可继续编辑。日常中文候选确认和正文换行不应误提交。

## 7 排序与两条筛选修正

1. 大纲拖到主题前后，预期同级顺序改变；拖到主题内部，预期改为其子主题。画布从主题拖到另一主题内部也应改父级。根不能移动到子主题内，环被拒绝，一次撤销恢复结构。
2. 给一个叶主题加“研究”标签，手动折叠其祖先；筛选“研究”时临时展开，清除筛选后恢复原折叠态。
3. 在该筛选中新增无标签子主题，筛选保持“研究”，提示切回全部查看；清除后新主题存在。选择筛选外的画布节点仍会按既有规则清筛选。

1. 把这次测试工程保存到未占用的新文件，关闭后仍用同一固定候选重开。
2. 用工作表下拉逐表查看：结构、默认/局部样式、关系标签箭头、外框概要、批注状态应与保存时一致。
3. 只补看新增管理窗口在125%/150%下的字段、滚动区、错误提示与按钮。每档集中看一次，不重跑旧恢复、旧删除、旧登录流程；已有本批同版本结果可以沿用。最后恢复Windows原比例。
