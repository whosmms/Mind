# 灵芽思维使用说明

这是 Windows 桌面程序。本机日常入口 `D:/mind/打开灵芽思维.cmd` 对应已合入 main 的版本。`D:/mind/打开最新开发版.cmd` 打开最新验证候选。源码和程序版本见随候选附带的 `候选程序校验.json`。候选分支仍待评审。

## 开始与保存

首页选择思维导图、鱼骨图、流程图或甘特图模板；也可打开已有`.lingya`工程。最近工程条目的移除只清历史记录，不删除文件。返回首页后，可以继续刚才的编辑。

点首页“浏览24种结构与场景模板”，按四类图选择知识树、目标拆解、根因分析、时间轴、审批、项目计划等可编辑模板；没有付费锁定。编辑器顶部“开始→模板”选择完整模板时，会插入新工作表并保留当前内容。思维导图还可直接选双向、向左、向右、向上、向下结构；仅重排现有主题并清除手动位置，可后退恢复。

用Ctrl+S保存，首次保存选择文件名；Ctrl+Shift+S另存为。关闭、重开或新建时的未保存提示可以取消，取消后保留当前内容。恢复预览只在存在有效副本时出现，采用后仍需正式保存。请把自己的工程另存到个人资料目录，避免修改随包样例。

通过「文件 → 本机版本历史」查看最近十次内容有变化的正式保存。选择一条可以查看保存时间、工作表数和修订，点「打开为副本」后用新文件名另存。历史位于工程同目录的「灵芽备份」中，每个工程单独保留。属于该工程的旧 `.bak` 在内容与现有历史不同的情况下也会显示为「覆盖前备份」。

## 导图、鱼骨与属性

单击选择主题，F2改名，Tab新增子主题，Enter新增同级，Delete删除；根主题不能删除。Ctrl+Z后退（撤回上一步编辑），Ctrl+Y或Ctrl+Shift+Z前进（恢复刚撤回的编辑）。可在大纲与画布定位同一主题，折叠只影响显示。

右侧属性分样式、图标、备注、任务四页。样式选项点击即生效；自填颜色、字体输入完成后离开输入框或按Enter生效，无须再点“应用样式”。滚轮经过收起的选项和数值框只滚动侧栏，修改数值请点击箭头、展开选项或用键盘。图标同样点选生效；备注与链接保留明确的应用按钮，避免未写完就存入内容历史。局部样式优先于工作表默认样式，恢复工作表样式会清除局部覆盖。窄窗可从“视图→属性”打开侧栏。

思维导图可用鼠标拖动主题自由摆放，整条下级分支一起移动，根主题也可拖。松手后保存位置；Esc或移出画布取消本次预览。顶部或空白处右键“恢复自动布局”清除手动位置，可后退恢复。自由摆放允许重叠，需要自己留出空间。按住Alt拖到另一个主题上，或在大纲拖动，才会改变父级；鱼骨图保持自动鱼骨布局，拖动用于改变层级。

主题选中或悬停时右侧出现“＋”，单击立即添加子主题；手动摆放后会先寻找附近空位，双击主题改名。右键主题可新增同级、关联任务、复习卡片、批注或图片，也能打开标签和属性。导图右键空白处可在点击位置创建子主题，父级为当前选中主题，无选中时为根主题；鱼骨入口明确自动排布。

在思维导图或鱼骨图中，右键主题选「专注此分支」，画布会放大当前分支并淡化其他主题。专注中仍可编辑。按 Esc 或点底部「退出专注」恢复进入时的缩放、位置和原有折叠显示。

关系线用于主题间关联：右键来源主题选“从此主题创建关系线”，再单击目标，Esc或点空白取消。按Ctrl依次单击多个主题，右键选“添加外框”或“添加概要”；须至少两个同父且连续的兄弟主题，非法选区会提示原因。移动和删除时外框、概要会按原规则维护成员，所有内容操作均可后退撤回。

## 工作表与剪贴板

底部选择工作表，旁边可新建，工作表菜单可改名、换结构或删除。有复习卡、讲解路线或文稿引用的工作表会阻止删除，请先在对应页面主动处理引用。

Ctrl+C复制，Ctrl+X只标记待移动，Ctrl+V才执行；剪切后可切表再粘贴，主题及学习记录的ID按命令规则保留。跨边界关系、半个分组、讲解路线或文稿引用等无法完整迁移时显示影响原因并保留源数据。内容编辑可能使剪切令牌过期，重新剪切即可；单纯切表不会让令牌过期。

从笔记或文档复制缩进文本或 Markdown 列表，再在画布或大纲右键父主题，选「粘贴大纲为子主题」。每行生成一个主题，空格或 Tab 表示层级，预览里可核对父子顺序。点「加入导图」一次写入，Ctrl+Z 可撤回整批。

## 流程图与任务

流程图右键空白可在点击处创建处理、判断、起点、终点、输入/输出节点；节点右侧“＋”一次创建后续节点并连线。双击节点编辑。单击来源节点端口，再单击目标节点端口即可建线；也保留端口拖到端口。Esc或点空白取消未完成的连线。

对齐且相向的端口会直接连线。端口错位或中间有节点时，程序优先选择短、少转折的自动路线。拖动节点时连线会重新走线。

单击线身可以选中连线，双击或右键可编辑。选中后拖动两端的圆点可以重接到其他端口，落在空白处或非法端口时会保留原连接。连接的标签、样式和后退历史仍可使用。带有旧手动曲线的工程打开后也按自动路线显示。

在主题上设为任务，或在任务工具页新建独立任务。任务属性可编辑日期、进度、里程碑与前驱；结束早于开始、依赖成环等会拒绝提交。甘特图拖动日期或边缘调整工期仍通过同一任务命令。

甘特空白处右键可新建任务，任务条右键可编辑，不必先寻找菜单。

## 插入图片

四类图都可从“插入→画布图片”添加图片，或在空白位置右键“在此插入图片”。画布图片可拖动移动；选中后拖右下角圆点等比例缩放，Delete或右键移除。Esc取消未完成拖动。导图、鱼骨图和流程图的节点还可右键“插入 / 更换节点图片”，图片随主题一起移动，布局时计入主题尺寸；“移除节点图片”只移除嵌入副本。

也可以把一张本地图片拖到画布空白处，或拖到导图、鱼骨图、流程图的节点上附着或更换。截完图后让画布获得焦点，按 Ctrl+V 将剪贴板图片放到视口中央。甘特图支持画布图片。

支持PNG、JPEG、BMP及GIF首帧，导入时读取原图并转为受限PNG嵌入工程，不修改原文件。复制`.lingya`即可带走图片，无须另外复制原图片。PNG/PDF导出包含图片，文字大纲只含文字；AI材料当前只取标题与备注，不自动上传嵌入图片。单张导入原文件上限20MiB/6400万像素，归一后最长边1024、PNG不超过256KiB；工程图片有总量与像素预算，工程仍受10MiB文件上限约束，过大时会明确拒绝。

包含图片、手动位置、曲线或新增方向结构的工程，应使用本候选或之后版本打开；旧严格读端会拒绝新字段或新结构，不会静默删除这些内容。

任务表选中筛选外目标时，可以点“显示全部任务”临时定位；点“恢复工作表筛选”回到原范围。临时定位不改工程保存的筛选。

## 复习、检查与讲解

左侧“复习”进入卡片管理和复习会话。点击“从导图选取…”，按工作表展开思维导图或鱼骨图，勾选想复习的主题，再点“加入复习”。一批卡片可以在主窗口一步撤回。每张卡片的正面是主题标题，答案优先用备注，其次用直属子主题的标题。已加入或缺少答案的主题会标明原因。

当前空闲时，加入后直接开始复习新卡片。正在复习时，当前题和进度会保留，下轮可切到“新卡片”后点“开始 / 重新开始”。先看正面，再翻面，选择重试、已复习或已掌握。源主题改变或删除时，按页面提示更新卡片、保留旧内容或移除卡片。长正反面可以分别滚动。

点「今日待复习」可直接开始到期队列。新卡当天可练，标为「已复习」后隔一天再练，标为「已掌握」后隔七天再练，按本地日期计算。来源有变的到期卡会在列表中提醒，处理来源后才能加入队列。

在导图或鱼骨图的画布、大纲右键主题，选「复习此分支…」。窗口默认开始该主题及其下级的今日到期卡，已折叠的主题也纳入范围。需要练本分支的全部卡时，切到「全部状态」再点开始；「从此分支选取…」可以在相同范围内补建新卡。

在列表中选一张卡，点「对照来源…」可并排查看已保存的题面、答案和原图当前内容。关闭对照会保留当前卡片，点「采用原图内容」才更新，并保留复习状态与最近复习时间。点「返回原主题」会关闭复习窗口并在画布上定位。原主题已删除时，仍可用原有的「转独立卡片」保留内容。

左侧“检查”列出当前规则问题，选中后定位对应主题或任务。可执行操作按该条问题提供，无法自动修复的内容由你编辑，刷新后再检查。

“视图”工具页的“讲解”或F5打开路线。可以保存主题顺序与演讲备注，开始后全屏播放；左右键切步骤，空格暂停或继续计时，Esc退出。备注默认隐藏，勾选后观众也会看到；长备注可滚动。退出恢复原选择、缩放和大纲显示，播放本身不写内容历史。

## 导出、搜索和设置

“创作→导出”可导出当前画布PNG、分页PDF，或完整大纲Markdown/TXT。PNG有像素上限，PDF先显示页数；文件写入失败会保留原文件。导出不包含选中框、待剪切虚线或流程端口。甘特按当前可见任务导出；大纲按完整主题顺序输出。

Ctrl+F搜索全工程的主题标题、备注和任务名称，包括折叠主题和未排期任务。点击结果定位；超过200条时显示总数和当前显示上限，不静默截断搜索结果。

首页底部或“创作与输出→设置与帮助”可设置本机配色和动作快捷键。保存前检查重复或系统保留组合，取消不应用；未修改的默认多组快捷键保留。设置不写工程。

## AI创作与工程文字稿

左侧“AI创作”分为材料生成导图、来源生成文稿两项。展开服务设置后可输入个人密钥，默认只保留本次会话；如需记住，使用Windows凭据。模型名称只影响之后的请求，点击应用不会自动联网，实际可用性以服务响应为准。

第一次使用可点“接入教程”：内置密钥申请、保存、模型选择、连接测试和常见错误说明，并附官方入口。打开教程不联网；点击外部链接才打开浏览器，点击连接测试或生成才发送API请求，可能产生费用。

导图先填写材料、模式及要求，点击生成后检查预览，再选择新工作表或当前主题子树并采用。补充内容标有“AI补充”；旧提案在来源内容变化后会拒绝采用，成功后不能重复采用。

文稿可选择整个来源表或当前子树，设置用途、篇幅和要求。预览中可逐段修改，确认后保存至工程；“创作→文字稿”支持继续改文、复制、导出、定位来源或可撤回删除。

右键导图或鱼骨主题，点「把分支整理为文字稿…」，可以直接在本机预览和保存。每个主题按导图顺序对应一段，备注作为正文，空段标为待补充。可在预览里改稿名，保存后进入该稿件。分支最多 100 个主题、序列化材料 20,000 字，超出时可选较小分支。

当段落引用的主题改了标题、备注或被删除时，文字稿列表会在对应段落前显示「来源变更」。双击段落或点「对照来源…」，可以并排查看上次记录和当前原图。一段引用多个主题时，可在下拉框里逐个核对。「暂不处理」保留原标记。「保留正文并确认」只记录当前来源。「插入当前备注」先加到窗口内的正文预览，只有点「应用本段修改」才保存修改。确认或应用只处理当前段落，其他未保存的文字继续留在编辑窗口。

旧稿若能用原指纹核实原图，会补录来源。历史内容无法核实的段落显示「来源待核对」，可查看当前主题并确认今后的对照起点，正文仍由你决定。

在文字稿中点「把来源加入复习…」，可从这篇稿件关联的原主题中勾选建卡。答案仍取自导图的备注或直属子主题；已制卡或缺答案的主题有状态提示。建卡后可继续编辑并保存当前文字稿。

AI只有在明确点击生成或连接测试后才联网。断网、超时、响应格式错误或取消请求不会自动改图。自动回归使用假供应方及本机HTTP桩，不代表真实服务演示已完成。

## 安装与版本边界

便携包完整解压后，运行`program/lingya.exe`；安装包默认仅为当前用户安装，无须安装Qt。请保留全部动态库及插件子目录。安装器拒绝覆盖装有其他内容的陌生目录；卸载不删除用户数据目录，不递归清理自行添加的工程。

本候选支持Windows 10 1809及以上的兼容64位Windows。另一台无Qt电脑、真实输入法和DPI、完整操作及真实联网统一最终验收，尚未由自动测试代签。带文稿逐段来源快照的工程请使用 H054 或之后的版本打开，旧严格读端可能拒绝新增字段。

## 右上角账号入口（H051）

首页和编辑器的右上角都可以点“登录”，查看邮箱登录、注册和找回密码。显示“账号服务待接入”时，三个页面可预览，表单为只读。点“暂不登录”即可返回继续编辑，工程文件保存在本机。服务验证身份后，右上角显示“我的账号”，可查看身份并退出。

“文件 → 本机账号（旧）”保留用于访问旧账号资料的入口。维护者可在“文件 → 账号服务设置…”使用已有的认证适配器，相关说明见[已有认证适配器部署步骤](联网登录部署步骤.md)。项目正式使用的服务器由用户提供后接入。
