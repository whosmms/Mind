## 一、先准备（约2分钟）

1. 保存并关闭正在运行的旧版灵芽思维；旧窗口不会随源码更新自动变成新版。
2. 到 `D:\mind` 双击 `打开灵芽思维.cmd`，等待构建并启动。
3. 检查工具栏有“新增同级主题”和“删除主题及子主题”。看不到这两个按钮，说明可能仍是旧窗口，先不要验收。
4. 本聊天会给出一个新建的“人工验收/M1收尾验收_时间”文件夹。里面有4份样例、这份步骤、回报模板和“截图”文件夹。原有人工验收文件均保留。
5. 所有操作只用新建工程或该文件夹的样例。修改样例前先“另存为”成新的测试文件，保留样例供重复验证。

截图方法：按Win+Shift+S框选整个软件窗口，点截图通知后保存到该文件夹的“截图”；也可以截图后直接发到聊天。
如果出现异常，先截图并记录刚才的操作；不用反复重装环境，也不要用真实作业文件试删除。

## 二、中文输入、层级与多行（约4分钟）

1. 按Ctrl+N新建。在左侧选根节点“中心主题”，按F2。
2. 用拼音输入“课程项目”，在候选字还显示时停住，截图命名 `01-输入法预编辑.png`。
3. 验证候选预编辑期间按Enter不会误新增主题或直接结束标题编辑。候选确定后，再按Enter确认标题。若这里行为不对，记录真实现象，不勾“通过”。
4. 选根节点，按Tab新增“需求分析”，确认后自动选中新节点。
5. 在“需求分析”上按Enter，新增同级“开发实现”。预期两者都是根节点的直接子主题。
6. 在大纲选“需求分析”，按Tab新增“功能清单”；再按Tab新增“文件操作”。预期形成多层结构，画布与大纲一致。
7. 选“功能清单”，F2编辑：第一行写“功能清单”，按Shift+Enter，第二行写“输入与保存”，再按Enter确认。预期同一个节点内完整显示两行。
8. 分别点击画布和大纲中的“开发实现”；预期两边选中同一主题。双击画布节点可以改名。
9. 开一次改名框，随便输入后按Esc。预期原内容不变。
10. 点击“适应全部”，截图 `02-多级与多行.png`。

注意：普通Enter是新增同级，根节点Enter是新增子主题；编辑框里的Enter是确认，Shift+Enter才换行。Tab在编辑框里不应新增节点。

## 三、普通删除、取消与撤销（约3分钟）

1. 选刚创建的“需求分析”，按Delete。预期先弹出“确认删除子树”，显示要删的主题数量及相关影响，不直接删除。
2. 先点“取消”。预期节点、选中位置和内容保持原状。
3. 再按Delete，直接按Enter。预期默认是“取消”，仍不删除。
4. 再按Delete，明确点击“删除主题”。预期该分支及其后代消失，选择回到它的父节点，其他分支保留。
5. 按一次Ctrl+Z。预期整棵被删分支恢复；再Ctrl+Y重做，再Ctrl+Z恢复。
6. 截图 `04-撤销恢复.png`。
7. 选根节点按Delete。预期根节点保留，状态栏说明根主题不能删除；工具栏删除按钮为不可用状态。

## 四、有关联任务时怎么删（约3分钟）

使用 `02-关联删除样例.lingya`，不要把自己的工程当样例。

1. 文件→打开，选择这份样例，先Ctrl+Shift+S另存为“保留任务测试.lingya”。
2. 选“阶段2”，按Delete。预期提示：共2个主题、1条关系、1项外框/概要、1条批注、1张卡片、1项关联任务；截图 `03-删除影响确认.png`。
3. 点“保留任务并删除主题”。预期阶段2及其子主题被删；去视图→甘特图，原已排期任务条仍在。
4. 按一次Ctrl+Z。预期节点及关联内容恢复。回思维导图，另存或关闭本测试文件。
5. 重新打开原样例，先另存为“一起删除测试.lingya”；选阶段2→Delete→“连同任务一起删除”。预期节点被删，去甘特图时该已排期任务条消失；Ctrl+Z后恢复。

关联任务的source、依赖清理、卡片missing、关系/批注清理和一次撤销完整恢复已有自动集成测试。你无需编辑JSON；真人重点确认提示清楚、两种按钮能用、结果与撤销符合预期。
当前只绘制已排期任务；样例另有一个未排期独立任务，它不会显示成任务条。

## 六、100节点和画布浏览（约2分钟）

1. 打开 `03-一百节点样例.lingya`，先另存为“一百节点测试.lingya”。
2. 点击“适应全部”，用滚轮/放大缩小按钮改变比例，空白处按住左键拖动画布。
3. 在大纲中选择底部节点，点击“定位所选主题”，预期能找到目标且高亮一致。
4. 改名一个节点，撤销、重做、保存并重开，确认仍可编辑，没有崩溃或明显卡死；截图 `06-100节点.png`。
5. 如需检查折叠，打开 `04-折叠定位样例.lingya`：初始某分支后代隐藏，从大纲选中隐藏节点后会临时显示路径；重开仍遵守原文件折叠。此操作不等同已实现持久化折叠编辑。

缩放范围为25%—200%。节点很多时，最小比例下也可能不能全部塞进窗口，可配合拖动、滚动和定位；不因此误判成节点丢失。
