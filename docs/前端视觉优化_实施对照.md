| 最终要求 | 本批实现 |

| 专业Windows桌面布局 | Qt Widgets原生菜单、分组工具栏、可停靠大纲/属性栏、中央画布；没有迁移为网页 |
| 绿白米色、克制品牌 | 保留#247A62/#F6F8F5/#DDF2E7/#FFF0D0等规范配色，小型原创嫩芽标识；画布无装饰插画 |

| 左大纲、中央大画布 | 左栏220逻辑像素参考；窗口小于1400时自动收起右属性栏，也可用工具栏“视图”页的“属性”按钮手动显示 |
| 右侧分标签属性 | 样式、内容、任务三标签；预览来自当前文档/选择，编辑入口复用已验证的事务对话框 |
