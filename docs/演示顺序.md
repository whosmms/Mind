# 五分钟离线演示顺序

1. 从首页展示四类模板和最近工程，打开随包`06-offline.lingya`的副本，选主题并用右栏修改样式/图标/备注，演示一次撤销。
2. 从大纲定位主题，切换工作表；展示Ctrl+F跨表搜索。复制与剪切分开说明，跨表无法无损迁移的引用会明确阻断、保留源内容。
3. 展示鱼骨和流程样例；流程回路、有向边及自动布局均为真实工程数据。进入甘特，编辑里程碑或拖动任务日期，再撤销。
4. 打开复习会话，翻面并自评；打开检查助手，定位一条实际问题；F5使用默认路线讲解，左右切步和Esc退出，原视口恢复。
5. 导出PNG、分页PDF和大纲，实际打开产物。最后展示AI创作两条入口与文稿管理；只有决定使用个人密钥时才做真实联网。带“假响应”字样的随包样例只用于离线说明，不当作API成功证据。

说明版本时分别给出已合main、未合开发候选和实际测试SHA。自动回归、真人最终验收、真实API与无Qt跨机的证据不能互相替代。
