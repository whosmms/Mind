# 五分钟离线演示顺序

1. 从首页浏览结构和场景模板，打开随包 `06-offline.lingya` 的副本。用方向键选主题，按 Tab 新建并原地输入，Enter 确认。框选后一起改样式，按 Ctrl+Z 撤销。演示拖动整支时的对齐参考线，以及输入备注后切换主题自动保存。
2. 从大纲定位主题，切换工作表。按 Ctrl+H 查找并预览全部替换，确认后用 Ctrl+Z 一次撤销。复制与剪切分开说明，跨表无法完整迁移的引用会明确阻断并保留源内容。
3. 展示鱼骨和流程样例。点击相向且对齐的两个端口建立直线，再移动一个节点查看自动曲线。拖端点重接后撤销。在任意画布右键插图并移动或缩放。进入甘特，查看日期和任务名，编辑里程碑或拖动任务安排，再撤销。
4. 打开复习会话，翻面并自评；打开检查助手，定位一条实际问题。按 F5 使用默认路线讲解，左右切步和 Esc 退出。有扩展屏时选择观众屏，展示演讲者的私有备注和下一步。
5. 从「文件 → 导入导图…」打开随包的外部导图样例，另存 .lingya。导出 SVG 并在浏览器查看。再展示 PNG、分页 PDF、大纲、AI 创作两条入口和文稿管理。真实联网留给最终演示，离线样例的假响应单独说明。

说明版本时分别给出已合main、未合开发候选和实际测试SHA。自动回归、真人最终验收、真实API与无Qt跨机的证据不能互相替代。
