## 登记规则

1. 新缺陷先在本表加一行（编号、严重度、现象、负责人），再在开发日志写 `DEV-*` 详情。
2. 修复后把状态改为“已修复”并补证据（提交号/命令/测试名）。
3. 设计取舍类写明决定编号（D-*），不当作缺陷反复讨论。
4. 本表由丙维护；各模块维护人提交自己的现象与证据，不代签。
