## 3 清理时机决定（D-REC-001，待乙丙复核）

DEV-030原设计说明第2条中的“采用成功即清理”由本批修正取代：采用只把内容放入内存，不能视为已持久保存。
取舍：正式保存前磁盘上仍保留恢复项，重启可能再次提示；换取再次崩溃时仍可恢复。每工程成功快照上限仍为5份。
正式保存成功、明确放弃修改、恢复对话框“全部不采用”仍按既有规则清理；稍后再问、取消保存、保存失败、撤销保留副本。
若需回退，只回退本批补丁并明确重新暴露数据丢失风险，不改写乙原提交与历史测试。

3. 在任务管理器只结束这个灵芽思维测试进程；重新启动同一程序，确认恢复列表、预览主题与刚才一致。
4. 点击采用，确认正文恢复、显示修改星号；Ctrl+Z回采用前状态，再Ctrl+Y恢复采用后的内容。
