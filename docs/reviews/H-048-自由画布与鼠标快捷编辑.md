# H048 自由画布、鼠标添加与模板

用户要求减少添加功能的操作步骤，并在本轮连续追加自由拖动、流程曲线、图片、模板和属性便利性。基于PR53的71c9630继续，分支feature/a/free-layout-flow-connect；main仍为faeac4b。按用户单人实现授权推进，不把原乙命令/布局、丙业务成果记作本轮贡献，也不产生虚假的非作者签收。

## 方案与实现

自由位置允许用户自行重叠，自动布局仍保留。选择可选绝对中心坐标覆盖自动结果，比绕过树模型创建无父节点更能保留已有任务、复习卡片、分组和结构命令。默认拖整条分支只改位置，Alt和大纲拖动才改层级；根也可移动。松手一次事务，取消只恢复预览，自动布局可后退。

流程图保留原自动避障走线；手动曲线选择一个中点，便于鼠标编辑和稳定存盘，取舍是手动曲线不承诺自动避障。点击两端口或端口拖动直接建线；选线拖线身/中点改变弯曲度，拖端点重接。原边ID、文字、样式保持，重复边和非法落点不破坏原连接。右键可恢复自动走线。

主题和流程节点提供悬停/选中“＋”；流程一次创建节点及连线。节点右键汇集新增同级、关系、外框概要、批注、任务、卡片、标签、属性、粘贴及图片。Ctrl点选兄弟后可直接建立分组，非法选区沿用命令错误解释。空白右键在原点击坐标创建主题/流程节点或图片；甘特右键新增任务或编辑任务条。

图片采用本机只读导入、规范化PNG嵌入，复制工程即可携带，避免外部路径失效。支持四图种画布图片，拖动、等比缩放、Delete/右键移除及后退；树/流程另有节点内图片，测量和绘制一致。PNG/PDF导出包含图片并排除加号、端口、缩放及曲线手柄。AI材料只取原有标题/备注，不自动发送图片。

模板库24份：导图8、鱼骨4、流程8、甘特4。缩略图来自模板自身结构，不是锁图或截图占位；首页创建工程走未保存保护，编辑器选择模板插入新表并保留旧表。现有导图支持双向、左、右、上、下布局切换，清除手动位置，可后退。

右侧样式明确选择后立即生效，自填值在完成输入后生效，取消“应用样式”按钮；备注仍保留应用，避免未写完就进内容历史。收起的选项/数值滚轮交给侧栏，不再误改。品牌图文间距压缩。AI内置可滚动接入教程和官方链接，打开教程不发出请求。

## 共享接口与兼容性

IF-A-20261107-010/011/012修改前已记入开发日志，D-CANVAS-20261107-001和D-TEMPLATE-20261107-001记录取舍。持久化均经CommandService。

- TreeNode.manualPosition、FlowEdge.bendPoint、BaseNode.imagePng、SheetBase.images为可选JSON扩展；未使用新功能的旧字段序列化保持原样，旧工程可读。含新字段或left/down/up的新工程需用新版打开；旧严格读端明确拒绝，不静默丢弃。
- TreeLayout.layout()仍是纯数据自动布局，根在原点；withManualPositions()才叠加手动坐标。方向布局通过尺寸和坐标变换保持不重叠。结构迁移/粘贴重用目标布局，避免继承旧表屏幕坐标。
- 单图PNG≤256KiB、最长边1024；源文件≤20MiB/6400万像素；工程嵌入图总编码≤6MiB、总像素≤16777216，文件仍≤10MiB。位置有限且在±100000内，图片显示尺寸1至2000。QtGui为Widgets既有冻结运行库，没有引入QtSvg、新Kit或新系统安装要求。
