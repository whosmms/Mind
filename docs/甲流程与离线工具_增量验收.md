## 1 流程图编辑、连线与撤销

1. 双击本次候选入口。选择“文件→打开”，选候选 `样例/05-flow.lingya`。看到“开始”“验收通过？”“完成”和“是”“否，重试”两条判断分支，回边绕到外侧。
2. “编辑→流程图→新增流程节点…”，标题填“处理异常”，类型选“处理”，横坐标填 `-280`、纵坐标填 `350`，点“应用”。新增矩形，原节点位置不变。再试一次新增但点“取消”，节点数不增加。
3. 按住“验收通过？”左侧绿色小圆点，拖到“处理异常”右侧绿色小圆点再松开。连线窗口预填起终点和左右端口；标签填“待处理”，点“应用”，再点“关闭”。看到有箭头、标签的折线。再次建立完全同端点/端口连接时，窗口显示重复错误，原线不增加。
4. 双击线或标签，选择该线，可改标签/端口。方向在已有连线上可选“终点箭头/双向箭头/无箭头”，点“应用”后立即刷新；关闭保留已应用内容。
5. 拖节点正文（避开绿色端口）到空白处松手。按一次 Ctrl+Z 恢复位置，再 Ctrl+Y 重做。“编辑→流程图→移动吸附到20像素网格”可切换吸附。
6. “编辑→流程图→自动布局”，节点重新排布；一次 Ctrl+Z 恢复原手动位置。允许自环与回路，不应弹“树存在环”的错误。
7. 选一个新建节点，按 Delete；先点“取消”应完整保留，再确认删除应同时移除它的连线。一次 Ctrl+Z 恢复。请勿把此样例另存覆盖原始样例；用新名字保存，再打开确认形状、位置、方向和标签保留。

## 2 任务、里程碑和双向选择

1. 打开 `样例/06-offline.lingya`。选带顶部任务徽标的主题，点击徽标，或“离线工具→编辑所选任务…”。“视图→任务表（全部工作表）”可显示底部表格。
2. 名称改“阶段检查”，点“单独应用名称（与关联主题同步）”。任务表和主题一起改名。此操作独立产生一条撤销；未点该按钮时，“应用属性”会提示先处理名称，不静默丢弃输入。
3. 勾“已排期”，开始填 `2026-10-31`，结束填 `2026-11-02`，再勾“里程碑”，点“应用属性”。预期显示“里程碑须同日”类错误，窗口保留、工程未改变。
4. 将两日期都设成 `2026-11-05`，进度 `60%`，点“应用属性”。“视图→甘特图”看到菱形里程碑，主题徽标和任务表显示对应日期/进度；一次 Ctrl+Z 撤销这次属性修改。
5. 单击甘特条/菱形，表中应选中同一任务；在甘特页单击任务表行只同步选中，保留当前页以便拖动。要跳到源主题，点击任务表下方“定位关联主题”；独立任务没有来源时按钮禁用。在导图页点击有任务主题，表格回到对应行。
6. 属性窗口“解除关联”保留两边标题；删除任务会提示，取消不删除，确认后主题仍保留、任务徽标消失，Ctrl+Z可恢复。保存到新文件再打开核对日期、里程碑、名称、进度。

## 3 离线复习与来源变化

1. 可断网操作。打开 `06-offline.lingya`，选择“离线工具→复习卡片…”，先看正面，点“翻面”看到答案。
2. 点“重来”：回队尾，不改学习状态。再翻面，点“已掌握”，进度完成、列表状态变“已掌握”。关闭窗口后，Ctrl+Z可撤自评，Ctrl+Y可重做。
3. 修改卡片对应主题标题，再打开复习卡片。列表应提示“来源已变”，该 linked 卡片不直接进入复习。
4. 选中它，点“更新卡片”：正反面按当前来源更新，已掌握状态和最近复习时间保留。点“开始/重新开始”后可复习。
5. 若选择“保留自定义”，卡片作为当前快照继续复习；源被删除后可“转独立卡片”。这些操作都立即保存，可在主窗口撤销。不存在来源的独立卡片不应误跳到其他节点。
6. 保存到新文件、重开，再看状态和来源说明。没有答案的叶节点点击“所选主题加入复习”时应明确提示内容不足，不能生成空答案卡。

## 4 检查侧栏与增量界面检查

1. 在流程图新增一个“处理”节点，不连出口，选择“离线工具→检查当前工程”。右侧应出现对应流程建议；双击问题可切到该工作表并定位节点。
2. 修正问题后列表应刷新；撤销修正后建议恢复。跨表定位不占内容撤销、不改变修订，因此原剪切和AI来源修订不会只因定位而失效。
3. 在复习卡片来源变化后检查工程，看到来源问题；从问题动作进入复习窗口更新卡片后，问题消失。讲解路线修复和流程主题色暂未接线的项目会明确说明，不能静默修改别的主题。
4. 仅检查这些新窗口：在流程标题、任务名称中用真实中文输入法选字，确认候选阶段不会提前提交；在当前常用DPI（可选125%或150%）检查按钮可见、文字不遮挡。旧M0三档DPI不要求整套重测。
